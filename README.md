# Автотесты API — тестовое задание

Проект с автотестами для Java-приложения из тестового задания. Приложение принимает запросы на вход пользователя, выполнение действия и выход из системы.

Тесты отправляют HTTP-запросы и проверяют ответы приложения. Вместо настоящего внешнего сервиса используется WireMock.

**Стек:** Java 17+, JUnit 5, WireMock, Allure Report, Maven. Приложение и WireMock запускаются и останавливаются автоматически.

## Быстрый запуск

Нужны JDK 17 или выше, интернет для первой загрузки зависимостей и исходный JAR в `sut/`. JAR из предоставленного архива уже включён в проект.

Проверьте Java:

```bash
java -version
```

Запустите тесты из корня проекта.

**Linux / macOS:**

```bash
./mvnw clean test
```

**Windows (PowerShell):**

```powershell
.\mvnw.cmd clean test
```

## Результат запуска

Полный набор содержит **113 проверок**. Для исходного приложения ожидается: **110 успешных, 3 неуспешных, 0 ошибок окружения, 0 пропущенных**. Все три неуспешные проверки относятся к одному подтверждённому дефекту AQA-001. Подробности последней проверки и среда выполнения записаны в [результатах тестирования](docs/TEST_RESULTS.md).

## Отчёт Allure

В папке `reports/` уже есть [готовый отчёт Allure](reports/allure-report.html). Для просмотра скачайте HTML-файл и откройте его в браузере.

Также можно создать свой отчёт по результатам нового запуска тестов. После выполнения тестов используйте команду:

**Linux / macOS:**

```bash
./mvnw allure:report
```

**Windows (PowerShell):**

```powershell
.\mvnw.cmd allure:report
```

Откройте его через локальный сервер:

**Linux / macOS:**

```bash
./mvnw allure:serve
```

**Windows (PowerShell):**

```powershell
.\mvnw.cmd allure:serve
```

В отчёте есть:

- названия сценариев и шагов;
- группировка по входу/выходу, API-ключу, валидации и внешнему сервису;
- запросы к приложению, HTTP-статусы и тела ответов;
- журнал обращений к внешнему сервису;
- сведения о версии Java и тестовом окружении.

Страница **Overview** показывает общую картину, **Behaviors** — результаты тестов, сгруппированные по функциям приложения, **Categories** — причины неуспешных проверок. Открыв проверку, можно увидеть ожидаемый результат и фактический ответ.

Файлы после запуска:

| Путь | Содержимое |
| --- | --- |
| `target/site/allure-maven-plugin/` | HTML-отчёт после `allure:report` |
| `target/logs/application.log` | Лог тестируемого приложения |
