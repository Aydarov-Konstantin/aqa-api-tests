## Область проверки

| Требование | Проверки | Класс |
| --- | --- | --- |
| API-ключ проверяется для каждого запроса | Отсутствующий, пустой, неверный ключ, регистр, суффикс; для всех трёх действий | `ApiKeyTest` |
| Отклонённый запрос не меняет сессию | Ошибочный LOGIN не создаёт сессию; ошибочный LOGOUT не удаляет её | `ApiKeyTest` |
| Токен содержит ровно 32 символа A–Z0–9 | Длины 0, 1, 31, 32, 33, 256; цифры; буквы; запрещённые символы; отсутствие параметра | `InputValidationTest` |
| Разрешены только LOGIN, ACTION, LOGOUT | Отсутствующее, пустое, неизвестное действие; неверный регистр | `InputValidationTest` |
| LOGIN вызывает /auth и сохраняет сессию при успехе | Вход, вход после выхода, действие после входа | `SessionLifecycleTest`, `ExternalServiceTest` |
| ACTION доступен только после LOGIN | До входа и после выхода обращений к /doAction нет | `SessionLifecycleTest` |
| Каждое ACTION вызывает /doAction | Одно и несколько действий, проверка количества запросов | `SessionLifecycleTest` |
| LOGOUT удаляет токен | Выход, запрет дальнейших действий, повторный вход | `SessionLifecycleTest` |
| Сессии независимы | Два пользователя: выход одного не влияет на другого | `SessionLifecycleTest` |
| Исходящие запросы соответствуют описанию | POST, точный путь, оба заголовка, form-тело только с нужным токеном, количество запросов | Общие проверки во всех сценариях с внешними вызовами |
| Учитывается HTTP-код внешнего ответа, а не тело | HTTP 200 с пустым телом, текстом, повреждённым JSON, телом ERROR; HTTP 4xx/5xx с телом OK | `ExternalServiceTest` |
| Ошибка аутентификации не создаёт сессию | Внешние HTTP 400, 401, 403, 404, 429, 500, 503; обрыв связи | `ExternalServiceTest` |
| Ошибка действия не завершает сессию | Повторное действие после восстановления сервиса, локальный выход после ошибки | `ExternalServiceTest` |
| Ответы соответствуют JSON-контракту | Content-Type; точное тело успешного ответа; result=ERROR и непустой message при ошибке | Общие проверки |
